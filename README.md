# Send Button Animation

A playful email send concept for Gmail and Apple Mail. An animated cursor clicks the original send control, which folds into a paper plane and flies away.

## Try it

Open `index.html` in a browser. Click **Play both** or either phone's send icon. Use **Slow motion** to inspect the fold and **Undo** to restore the demo draft.

If your device prefers reduced motion, explicitly select **Enable animation** to preview the motion.

The demo is self-contained and runs without installation. It simulates sending; no email is sent.

## Recording

`demo.mp4` contains the recorded interaction. The interactive version includes iPhone-style frames, original send icons, a cursor approach and click ripple, replay, and Undo.
